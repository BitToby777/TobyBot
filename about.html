Hello Human! You have found the right place to learn about all the quirks and chips of TobyBot!


TobyBot is a simple dude, so he only tells you the facts that he knows are true. More creative adventures like storytelling or data analysis that you can do with other bots aren't in TobyBot. But cut him some slack, he is facing the beasts of the robot universe, being coded by a high schooler named Toby. This is Tobyhuman, not TobyBot!


After you give TobyBot a topic, he looks through the Wikipedia article of that topic and pulls out every single sentence that can become a fact, making sure to get rid of the headlines and quotes that don't lead to specific facts. Then, TobyBot checks how well your words match with the fact, which all go into the juice of TobyBot. Finally, TobyBot will keep on telling you information about your question until no more matching facts are left. You can use him forever and have deep conversations about the most niche topics all around. The bigger the topic, the longer an answer will take, but this website shouldn't make you fall asleep at your screen!


TobyBot uses Python code for the functions that load data for a given topic from Wikipedia into a list and match user questions to facts in the list. The Python code sits behind a Fast API web server running in a Docker container. Client-side Javascript lets the user's browser communicate with the Fast API methods.
